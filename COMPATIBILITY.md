# Web Compatibility

Status terms: **Supported**, **Partial**, **Unsupported**, and **Broken**.

| Area | Status | Notes |
|---|---|---|
| Native Windows shell | Supported | Windows 10/11 x86_64; resize, window controls, basic input |
| HTML | Unsupported | Parser milestone not started |
| DOM | Unsupported | Not implemented |
| CSS/style/layout | Unsupported | Not implemented |
| HTTP/HTTPS | Unsupported | Not implemented |
| JavaScript/browser APIs | Unsupported | Not implemented |
| Accessibility | Unsupported | Native content accessibility tree not implemented |

Compatibility is updated only when behavior has tests. Test fixtures are organized under `tests/web/` as implementation lands.
